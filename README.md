# 🛡️ Data Governance & Stewardship Framework (DAMA-DMBOK)
> **Projeto Bilingue / Proyecto Bilingüe:** Português (PT-BR) | Español (ES)

---

## 🇧🇷 Português (PT-BR)

### 📌 Sobre o Projeto
Este repositório contém a implementação prática de um **Programa Corporativo de Governança de Dados, Qualidade e Data Stewardship**, estruturado com base nas melhores práticas do **DAMA-DMBOK** e em conformidade com leis de privacidade de dados (**LGPD/GDPR**).

O objetivo é simular o ciclo de vida real de governança em uma empresa, abrangendo desde a definição de políticas e papéis operacionais até a gestão de metadados e validação técnica via SQL.

### 🗂️ Estrutura do Repositório
* `01_GOVERNANCE_CHARTER/`: Carta de Operacionalização da Governança e Matriz RACI dos Data Stewards.
* `02_METADATA_DATA_DICTIONARY/`: Glossário de Negócio, Catálogo de Metadados e Linhagem do Dado (*Data Lineage*).
* `03_DATA_QUALITY_SQL/`: Regras de Qualidade de Dados e Scripts SQL para Auditoria e Diagnóstico de Bases.
* `04_LGPD_INCIDENT_FLUX/`: Fluxo de Atendimento ao Titular de Dados e Guia de Resolução de Incidentes do Data Steward.

### 🛠️ Tecnologias e Metodologias
* **Framework:** DAMA-DMBOK (Data Management Body of Knowledge).
* **Consultas e Auditoria:** SQL Avançado (Google BigQuery / AWS Athena).
* **Documentação & Metadados:** Markdown, Git, GitHub, BPMN.
* **Compliance:** LGPD (Lei Geral de Proteção de Dados) e GDPR.

## 🇪🇸 Español (ES)

### 📌 Sobre el Proyecto
Este repositorio contiene la implementación práctica de un **Programa Corporativo de Gobernanza de Datos, Calidad y Data Stewardship**, estructurado en función de las mejores prácticas de **DAMA-DMBOK** y en cumplimiento con las leyes de privacidad de datos (**LGPD/GDPR**).

El objetivo es simular el ciclo de vida real de la gobernanza en una empresa, abarcando desde la definición de políticas y roles operativos hasta la gestión de metadatos y la validación técnica mediante SQL.

### 🗂️ Estructura del Repositorio
* `01_GOVERNANCE_CHARTER/`: Carta de Operacionalización de Gobernanza y Matriz RACI para los Data Stewards.
* `02_METADATA_DATA_DICTIONARY/`: Glosario de Negocio, Catálogo de Metadatos y Linaje de Datos (*Data Lineage*).
* `03_DATA_QUALITY_SQL/`: Reglas de Calidad de Datos y Consultas SQL para Auditoría y Diagnóstico de Bases.
* `04_LGPD_INCIDENT_FLUX/`: Flujo de Atención al Titular de Datos y Guía de Resolución de Incidentes del Data Steward.

### 🛠️ Tecnologías y Metodologías
* **Marco de Trabajo:** DAMA-DMBOK.
* **Consultas y Auditoría:** SQL Avanzado (Google BigQuery / AWS Athena).
* **Documentación y Metadatos:** Markdown, Git, GitHub, BPMN.
* **Cumplimiento:** LGPD y GDPR.
